# Freelance Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colours, responsive styles and visual effects
- `script.js` — mobile menu, active navigation and contact links

## Run it locally
1. Download and extract the ZIP.
2. Open the `freelance-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Important
The portfolio uses Google Fonts from an online service. If the visitor is offline, the browser will fall back to system fonts. No backend or build step is required.
